# 视频复刻流水线

个人 Codex Skill：把一个视频链接或本地视频自动整理成可复刻的分镜生产包。

## 默认产物

- 原始视频信息与运行清单
- 每 2 秒一张的源视频抽帧
- 中文逐帧图片生成提示词
- 对应分镜图片
- 统一命名的 `shot-XX_时长_场景名.png`
- 每张图片对应的 3–5 秒中文图生视频提示词
- 通用中文负面提示词
- 联系表、README 和 4K 后期建议

## 使用示例

- “复刻这个视频：https://……”
- “用 video-remake-pipeline 处理这个本地视频。”
- “每两秒截一张，生成全部图片和视频提示词。”

## 本地依赖

- `ffmpeg` 与 `ffprobe`：读取视频、抽帧和生成联系表
- `yt-dlp`：下载用户提供的公开网页视频链接
- Codex 可用的图片生成工具：生成分镜图片

不会绕过登录、付费墙、DRM 或网站权限。外部生图平台不可调用时，仍会完整交付可复制的提示词。
