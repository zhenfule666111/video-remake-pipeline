# Video Remake Pipeline · 视频复刻流水线

> **看到一个想复刻的视频，只要把链接或文件交给 Codex。**<br>
> 它会把视频拆成一套可直接继续制作的中文分镜生产包。

很多视频“看起来很美”，真正复刻时却会卡在一连串琐碎工作里：下载、抽帧、识别镜头语言、反推提示词、统一人物比例、生成分镜、设计运镜，再考虑 4K 输出。

**Video Remake Pipeline 把这条链路一次串起来。** 它交付的不只是几句 Prompt，而是一套按 Shot 编号、可以继续生图、生成短视频和剪辑的完整工作文件。

## 一句话开始

把这个仓库安装为 Codex Skill 后，直接告诉 Codex：

> 复刻这个视频：https://……<br>
> 每两秒截一张，反推中文图片提示词，生成全部分镜图，再为每张图写 3–5 秒的图生视频提示词。

本地文件也可以：

> 用 `video-remake-pipeline` 处理这个本地视频，并整理成完整分镜生产包。

## 从一条视频到一套可制作分镜

```mermaid
flowchart LR
    A[视频链接或本地文件] --> B[探测视频并每 2 秒抽帧]
    B --> C[分析构图、尺度、光线与美术风格]
    C --> D[反推逐帧中文图片 Prompt]
    D --> E[生成并统一命名分镜图片]
    E --> F[编写 3–5 秒图生视频 Prompt]
    F --> G[联系表、清单与 4K 后期方案]
```

## 你最终会拿到什么

| 产物 | 用途 |
| --- | --- |
| `manifest.json` | 记录源视频、时间点、镜头编号、时长与文件路径 |
| `frames/` | 按时间轴抽取的原始参考帧 |
| `contact-sheet.jpg` | 一眼浏览整支视频的镜头节奏和场景变化 |
| `image-prompts-zh.md` | 每个 Shot 一条独立、可复制的中文图片生成提示词 |
| `generated/` | 与参考帧逐一对应的最终分镜图片（图片生成可用时） |
| `video-prompts-storyboard-zh.md` | 每张图片对应的 3–5 秒中文图生视频提示词 |
| `4k-finishing-guide-zh.md` | 放大到 4K 的工具选择、参数方向和避坑建议 |
| `README.md` | 本次运行的镜头数量、建议总时长和交付索引 |

分镜图片统一命名，例如：

```text
shot-01_5秒_古松云台.png
shot-02_4秒_白玉通天殿.png
shot-03_4秒_金光云雾天门.png
```

## 不只是“描述画面”

这套 Skill 会主动处理复刻中最容易失控的细节：

- **尺度感**：用人物作为参照，控制人物与巨型建筑的比例，避免人物抢画面或小到不可读。
- **风格一致性**：先建立全片视觉基准，再逐镜写 Prompt，减少材质、色彩和世界观漂移。
- **亮度与氛围**：针对仙宫、神殿、云海等题材，强化珍珠白、暖金、体积光和清透空气，而不是生成灰暗脏黄的画面。
- **可生成的运镜**：每个镜头只使用一种缓慢稳定的主要运动，人物只做轻微走动，尽量降低建筑融化和画面闪烁。
- **逐镜可追溯**：抽帧、图片 Prompt、生成图、视频 Prompt 和文件名始终使用同一个 Shot 编号。
- **真实的能力边界**：外部生图平台不可调用时，仍会交付完整提示词；不会把“提示词完成”说成“图片已经生成”。

## 默认工作方式

| 项目 | 默认值 |
| --- | --- |
| 抽帧间隔 | 每 2 秒一张，从 0 秒开始 |
| 图片画幅 | 保持源视频画幅；接近 16:9 时按 16:9 输出 |
| 单镜时长 | 默认 4 秒；建立场景或终章可使用 5 秒 |
| 输出语言 | 提示词、说明、标题和负面提示词均为中文 |
| 人物动作 | 缓慢走两三步，衣袖、衣摆与发丝轻微摆动 |
| 环境动作 | 云雾、水流、树枝与光尘缓慢自然运动 |
| 镜头运动 | 缓慢推近、拉远、横移、摇摄、升降或小幅环绕，单镜头不切换机位 |

## 本地依赖

- [`ffmpeg`](https://ffmpeg.org/) 与 `ffprobe`：读取视频、逐点抽帧并生成联系表。
- [`yt-dlp`](https://github.com/yt-dlp/yt-dlp)：下载用户提供的公开网页视频链接。
- Codex 当前会话可用的图片生成工具：生成对应分镜图片；不可用时自动退化为完整 Prompt 交付。

准备视频：

```bash
python3 scripts/prepare_video.py <视频链接或本地文件> \
  --output-dir <运行目录> \
  --interval 2
```

验证交付是否完整：

```bash
python3 scripts/validate_run.py <运行目录>
```

## 安全与来源边界

- 只处理用户提供或明确授权使用的视频。
- 不绕过登录、验证码、付费墙、地区限制或 DRM。
- 始终保留原始视频，不覆盖用户源文件。
- 调用需要登录、积分或付费的服务前，先说明服务与可能消耗。
- AI 放大可以改善观感，但不会把低清素材变成真正原生拍摄的 4K。
